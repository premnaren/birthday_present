# Plan 2.1: Chapter 0 — Sealed Diary Cover & Interactive Entry Gate

## Objective
Implement Chapter 0 as a tactile, sealed scrapbook/diary cover. Create handwritten input fields for name and birthday (styled like ruled notebook lines with torn paper date tabs), a 3D-styled red/gold wax seal "Open" button, gentle wobble feedback with playful hints after 3 attempts, and a GSAP cover-lift/seal-break animation that unlocks Chapter 1.
