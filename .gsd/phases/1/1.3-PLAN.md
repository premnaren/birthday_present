# Plan 1.3: Scrapbook Stage & Page Navigation Shell

## Objective
Create the primary HTML document shell (`index.html`), establish the scrapbook stage container with realistic book margins and paper grain, and build the navigation manager (`js/book-stage.js`) using GSAP to orchestrate chapter transitions, bookmark ribbon navigation, touch swipe support, and locked/unlocked state progression.

## Context
Load these files for context:
- .gsd/SPEC.md
- .gsd/REQUIREMENTS.md
- css/tokens.css
- css/scrapbook.css
- js/content-loader.js

## Tasks

<task type="auto">
  <name>Build index.html structure and book stage styling</name>
  <files>
    index.html
    css/book-stage.css
  </files>
  <action>
    1. In `index.html`:
       - Include mobile viewport configuration (`viewport-fit=cover, width=device-width, initial-scale=1.0`).
       - Add `<meta name="robots" content="noindex, nofollow">` to protect privacy.
       - Include OpenGraph meta tags with custom title ("A Belated Birthday Storybook for Kritika 📖✨").
       - Link all CSS files (`tokens.css`, `typography.css`, `scrapbook.css`, `audio-player.css`, `book-stage.css`).
       - Import GSAP core library via CDN (with reliable local fallback script).
       - Create the book stage layout:
         - `#book-stage`: The main container resembling an open or closed scrapbook journal.
         - `#bookmark-ribbon`: A hand-drawn fabric ribbon / tab bar showing chapter milestones (locked chapters sealed with washi tape until unlocked).
         - `#chapter-container`: Mount point for chapters 0 through Finale.
         - `#nav-controls`: Discrete, hand-drawn paper corner tabs and arrows for back/next navigation.
         - Audio toggle button mount.
    2. In `css/book-stage.css`:
       - Style the scrapbook container: cream-textured paper spread, realistic cast shadows on wooden/desk background, soft margins, and stitched book spine effect.
       - Implement responsive layouts:
         - Mobile (360px–430px): Single-page storybook spread, tactile thumb-friendly navigation.
         - Tablet/Desktop (>768px): Two-page open book spread with central binding fold.
       - Style the bookmark ribbon with silky gradient, textured fabric weave, and hanging tail.
    AVOID: Generic app header bars, fixed bottom tab bars, or corporate navigation menus.
    USE: Physical book bookmarks, paper tabs, and tactile page corner flips.
  </action>
  <verify>
    PowerShell:
    `Test-Path index.html; Test-Path css/book-stage.css`
  </verify>
  <done>
    `index.html` and `css/book-stage.css` provide the tactile storybook shell with responsive mobile and desktop viewports.
  </done>
</task>

<task type="auto">
  <name>Implement chapter transition engine and navigation manager</name>
  <files>
    js/book-stage.js
    js/app.js
  </files>
  <action>
    1. In `js/book-stage.js`:
       - Manage current chapter index (0: Gate, 1: Guess, 2: Friends, 3: Family, 4: Siblings, 5: Cousins, 6: Finale).
       - Manage chapter unlock progress (Gate unlocks Ch 1; visiting Ch 1 unlocks Ch 2, etc.; store progress in `sessionStorage`).
       - Implement page transitions using GSAP:
         - Forward turn: current page flips/slides left with shadow overlay, next page reveals smoothly.
         - Backward turn: reverse page flip animation.
         - Reduced-motion mode fallback: clean gentle opacity crossfade.
       - Trigger `audioPlayer.playPageTurn()` on transition if sound is enabled.
       - Support navigation methods:
         - Tap on next/prev buttons
         - Keyboard arrow keys (Left / Right / Esc)
         - Touch swipe gestures (left/right swipe)
         - Direct jump from unlocked tabs on the bookmark ribbon
    2. In `js/app.js`:
       - Main bootstrap script initializing `contentLoader`, `audioPlayer`, and `bookStage`.
       - Render initial chapter placeholder views to verify smooth navigation end-to-end.
    AVOID: Harsh instant page swapping or disorienting 3D tumbling.
    USE: Tactile ease-out transitions mimicking physical paper turns.
  </action>
  <verify>
    PowerShell:
    `Test-Path js/book-stage.js; Test-Path js/app.js`
  </verify>
  <done>
    `book-stage.js` and `app.js` run chapter transitions, unlock tracking, ribbon sync, and touch gestures.
  </done>
</task>
