# Plan 1.1: Foundation & Tactile Design Tokens

## Objective
Establish the project directory structure, load curated typography, configure the paper-and-scrapbook design token system, and implement CSS/SVG utilities for authentic physical textures (torn paper, washi tape strips, paper grain, Polaroid photo frames, wobbly rotation offsets) complying with anti-template rules.

## Context
Load these files for context:
- .gsd/SPEC.md
- .gsd/REQUIREMENTS.md
- PRD.md

## Tasks

<task type="auto">
  <name>Create directory layout and core design tokens</name>
  <files>
    css/tokens.css
    css/typography.css
  </files>
  <action>
    Create the foundational CSS architecture:
    1. In `css/tokens.css`, define CSS custom properties for the palette:
       - Cream paper: `--color-paper: #FBF3E4`, `--color-paper-dark: #F3E7D0`
       - Blush pink: `--color-blush: #F4C2C7`
       - Dusty rose: `--color-rose: #D98A9B`
       - Soft lavender: `--color-lavender: #CDB8E3`
       - Butter yellow: `--color-butter: #F7E3A1`
       - Sage green: `--color-sage: #B7C9A8`
       - Ink text: `--color-ink: #4A3B3F`, `--color-ink-light: #7A656B`
       - Accent red: `--color-red: #C8483F`
       - Shadows: soft realistic craft paper drop-shadows (e.g. `--shadow-paper: 2px 4px 12px rgba(74, 59, 63, 0.08)`)
    2. In `css/typography.css`, import Google Fonts:
       - Headings/Script: 'Caveat', cursive / 'Permanent Marker'
       - Captions/Notes: 'Gaegu', cursive / 'Patrick Hand'
       - Body/Typewriter: 'Courier Prime', monospace / 'Lora', serif
       Define standard typography utility classes (`.font-handwriting`, `.font-heading`, `.font-typewriter`, `.font-caption`).
    AVOID: Pure black text (#000000), neon colors, generic system sans-serif defaults, and purple-to-pink gradient cards.
    USE: Warm ink tones, hand-lettered Google fonts, and textured cream paper backgrounds.
  </action>
  <verify>
    Test that `css/tokens.css` and `css/typography.css` exist and contain all required color variables and font imports.
    PowerShell:
    `Get-Content css/tokens.css | Select-String "--color-paper"`
  </verify>
  <done>
    `css/tokens.css` and `css/typography.css` are valid CSS files declaring the complete palette and typography tokens.
  </done>
</task>

<task type="auto">
  <name>Build tactile scrapbooking CSS and SVG texture utilities</name>
  <files>
    css/scrapbook.css
    assets/textures/paper-grain.svg
  </files>
  <action>
    Create tactile scrapbooking components and SVG masks/filters:
    1. In `assets/textures/paper-grain.svg`, create an inline SVG noise/grain filter to give surfaces authentic paper tooth without heavy PNG downloads.
    2. In `css/scrapbook.css`:
       - Define `.paper-grain` overlay with SVG filter and subtle opacity.
       - Create washi tape styles (`.washi-tape`, `.washi-tape-pink`, `.washi-tape-sage`, `.washi-tape-yellow`) with semi-translucent pastel backgrounds, ragged tape ends using CSS clip-path or zig-zag borders, and slight rotation.
       - Create Polaroid frame styles (`.polaroid-frame`) with thick bottom borders, slight glossy texture, worn borders, and pin/tape anchors.
       - Create torn paper edge utility (`.torn-edge`) with irregular border clip-paths.
       - Add rotation classes (`.tilt-left-sm`, `.tilt-right-sm`, `.tilt-left-md`, `.tilt-right-md`, ranging from -6deg to +6deg) to prevent rigid grid alignments.
       - Add hover/press wobble animations (`@keyframes gentle-wobble`).
    AVOID: Symmetrical card grids, harsh 90-degree boxes, and plastic drop-shadows.
    USE: Slight angles, ragged clip-paths, and tactile textures.
  </action>
  <verify>
    PowerShell:
    `Test-Path css/scrapbook.css; Test-Path assets/textures/paper-grain.svg`
  </verify>
  <done>
    Scrapbook texture styles and SVG paper grain exist, supporting Polaroid, washi tape, and torn-edge classes.
  </done>
</task>
